Rešen primer — Ali je sistem stabilen?

Podan je diferencialni enačaj sistema:

y′′′′+2y′′′+6y′′+4y′+y=x(t)y'''' + 2y''' + 6y'' + 4y' + y = x(t)y′′′′+2y′′′+6y′′+4y′+y=x(t)

1. Korak — Karakteristični polinom

Prevedemo diferencialni enačaj v Laplaceovo domeno (ob ničelnih začetnih pogojih):

s4Y(s)+2s3Y(s)+6s2Y(s)+4sY(s)+Y(s)=X(s)s^4 Y(s) + 2s^3 Y(s) + 6s^2 Y(s) + 4s Y(s) + Y(s) = X(s)s4Y(s)+2s3Y(s)+6s2Y(s)+4sY(s)+Y(s)=X(s)

Prenosna funkcija:

G(s)=Y(s)X(s)=1s4+2s3+6s2+4s+1G(s) = \frac{Y(s)}{X(s)} = \frac{1}{s^4 + 2s^3 + 6s^2 + 4s + 1}G(s)=X(s)Y(s)​=s4+2s3+6s2+4s+11​

Karakteristični polinom imenovalca:

P(s)=s4+2s3+6s2+4s+1P(s) = s^4 + 2s^3 + 6s^2 + 4s + 1P(s)=s4+2s3+6s2+4s+1

Koeficienti: a4=1, a3=2, a2=6, a1=4, a0=1a_4=1,\ a_3=2,\ a_2=6,\ a_1=4,\ a_0=1a4​=1, a3​=2, a2​=6, a1​=4, a0​=1

Nujen (ne zadosten) pogoj: vsi koeficienti morajo biti pozitivni. ✓

MATLAB — preveritev 

% Primer 2: s^3 + 2s^2 + s + 5
num = [1];
den = [1, 2, 1, 5];

% Odziv na stopnico — divergira (nestabilen sistem)
